# Material that spans sessions

Keep one scratch file: `notes/eat-<topic>.md` in the project, or
`.imo/notes/eat-<topic>.md` inside IMO. It contains:

- Source map: links, versions, dates, claim locations and evidence types.
- Findings labelled `source says (location)`, `we infer`, or `not checked`.
- Local comparisons and proposed adopt / maybe / reject rows.
- Revised beliefs in place: `~~old~~ -> new, because ...`, with the evidence.

Resume from the unresolved claims and their source locations. Do not create
another summary or a copy of the current findings. After confirmed rows are
applied and the targets re-read, delete the scratch file. If review is still
pending, leave it as the single unfinished working file.
